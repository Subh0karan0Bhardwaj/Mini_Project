# Project Description – The Randomizer

**The Randomizer** is a simple web-based mini project developed using HTML, CSS, and JavaScript. It is designed to make free time more interesting by providing random suggestions to users.

The website offers four different categories: Random Facts, Challenges, Activities, and Motivation. Users can select any category, and the website displays a random result from the selected category with just one click.

HTML is used to create the structure of the webpage, CSS is used to design and style the website, and JavaScript is used to generate random results.

**Main Features:**
- Four different categories to choose from.
- Generates random results with one click.
- Simple and user-friendly interface.
- Attractive purple-and-white design.
- No login or registration required.

**Technologies Used:**
- HTML – For webpage structure.
- CSS – For styling and layout.
- JavaScript – For random result generation.

**Objective:** The main objective of this project is to understand the basics of web development and JavaScript while creating a fun and interactive website.
